# 요청

AGENTS.md 기준으로 작업해줘.

이번 단계에서는 Enemy를 잡을 때 현재 점수가 올라가고 화면에 표시되도록 코드만 만들어줘.  
Unity Editor에서 필요한 작업은 내가 직접 할 거야.

## 작업 내용

1. `Assets/Scripts` 폴더가 없다면 생성
2. `Assets/Scripts/ScoreManager.cs` 생성
3. 기존 `Assets/Scripts/Enemy.cs` 수정
4. Enemy가 충돌로 사라질 때 현재 점수가 1 올라가도록 구현
5. 올라간 점수가 Text UI에 표시되도록 구현

## 구현 기준

- 현재 점수 Text UI는 Inspector에서 연결할 수 있게 해줘.
- 현재 점수는 0부터 시작하게 해줘.
- Enemy가 충돌로 제거될 때 점수가 1씩 올라가게 해줘.
- 점수가 올라가면 Text UI에 `현재 점수 : 점수` 형식으로 표시해줘.
- 예: `현재 점수 : 3`
- 최고 점수 UI는 아직 코드로 갱신하지 마.
- 초보자가 이해하기 쉬운 단순한 코드로 작성해줘.

## 제한 사항

- 이번 단계에서는 현재 점수 증가와 표시만 만들어줘.
- 다른 게임 기능은 아직 만들지 마.

## 완료 후 추가 보고 형식

- 새로 만든 스크립트 파일
- 수정한 스크립트 파일
- Inspector에서 연결해야 할 항목
- Unity Editor에서 직접 해야 할 작업
- Play 모드에서 확인할 내용
