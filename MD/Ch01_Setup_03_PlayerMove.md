# 요청

AGENTS.md 기준으로 작업해줘.

이번 단계에서는 플레이어 이동 코드만 만들어줘.  
Unity Editor에서 Player 오브젝트를 만들고 스크립트를 붙이는 작업은 내가 직접 할 거야.

## 작업 내용

1. `Assets/Scripts` 폴더가 없다면 생성
2. `Assets/Scripts/PlayerMove.cs` 생성
3. 키보드 입력으로 오브젝트가 움직이도록 구현

## 구현 기준

- 방향키 또는 WASD 입력으로 이동하게 해줘.
- 이동 속도는 Inspector에서 조절할 수 있게 해줘.
- 초보자가 이해하기 쉬운 단순한 코드로 작성해줘.
- 이동은 X, Y 방향으로만 처리해줘.

## 제한 사항

- 총알 기능은 만들지 마.
- 적 기능은 만들지 마.
- 점수나 UI는 만들지 마.
- 게임 오버 기능은 만들지 마.
- 요청한 내용 외에는 수정하지 마.

## 완료 후 추가 보고 형식

- 새로 만든 스크립트 파일
- Player 오브젝트에 붙여야 할 스크립트 이름
- Play 모드에서 확인할 내용
