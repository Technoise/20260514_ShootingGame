# 요청

AGENTS.md 기준으로 작업해줘.

이번 단계에서는 적의 이동 방향이 가끔 Player 쪽으로 바뀌도록 코드만 수정해줘.  
Unity Editor에서 필요한 작업은 내가 직접 할 거야.

## 작업 내용

1. 기존 `Assets/Scripts/Enemy.cs` 수정
2. Enemy가 생성될 때 이동 방향을 한 번 정하도록 변경
3. 일부 Enemy는 Player 방향으로 이동하고, 나머지는 기존처럼 아래쪽으로 이동

## 구현 기준

- Enemy가 생성될 때 랜덤으로 이동 방식을 정해줘.
- 일정 확률로 `Player` 오브젝트를 찾아서 그 방향으로 이동하게 해줘.
- Player를 찾지 못하면 기존처럼 아래쪽으로 이동하게 해줘.
- Update에서는 처음 정한 방향으로 계속 이동하게 해줘.
- 초보자가 이해하기 쉬운 단순한 코드로 작성해줘.

## 제한 사항

- 이번 단계에서는 Enemy 이동 방향 변경만 만들어줘.
- 다른 게임 기능은 아직 만들지 마.

## 완료 후 추가 보고 형식

- 수정한 스크립트 파일
- Player 오브젝트 이름 확인이 필요한 이유
- Unity Editor에서 직접 해야 할 작업
- Play 모드에서 확인할 내용
