# 요청

AGENTS.md 기준으로 작업해줘.

이번 단계에서는 적 충돌 처리 코드만 만들어줘.  
Unity Editor에서 필요한 작업은 내가 직접 할 거야.

## 작업 내용

1. 기존 `Assets/Scripts/Enemy.cs` 수정
2. Enemy가 다른 오브젝트와 충돌하면 상대 오브젝트를 제거
3. Enemy 자신도 같이 제거

## 구현 기준

- Unity 3D 물리 충돌을 기준으로 작성해줘.
- 충돌이 시작되면 Enemy와 충돌한 상대 오브젝트가 사라지게 해줘.
- 초보자가 이해하기 쉬운 단순한 코드로 작성해줘.

## 제한 사항

- 이번 단계에서는 적 충돌 처리만 만들어줘.
- 다른 게임 기능은 아직 만들지 마.
