# 요청

AGENTS.md 기준으로 작업해줘.

이번 단계에서는 플레이어가 총알을 발사하는 코드만 만들어줘.  
Unity Editor에서 필요한 작업은 내가 직접 할 거야.

## 작업 내용

1. `Assets/Scripts` 폴더가 없다면 생성
2. `Assets/Scripts/PlayerFire.cs` 생성
3. 발사 버튼을 누르면 총알이 생성되도록 구현

## 구현 기준

- 발사 입력은 `Fire1`을 사용해줘.
- 총알 프리팹은 Inspector에서 연결할 수 있게 해줘.
- 총알이 생성될 위치도 Inspector에서 연결할 수 있게 해줘.
- 버튼을 누르면 연결된 위치에 총알을 생성해줘.
- 초보자가 이해하기 쉬운 단순한 코드로 작성해줘.

## 제한 사항

- 이번 단계에서는 플레이어 발사 기능만 만들어줘.
- 다른 게임 기능은 아직 만들지 마.

## 완료 후 추가 보고 형식

- 새로 만든 스크립트 파일
- Player 오브젝트에 붙여야 할 스크립트 이름
- Unity Editor에서 직접 해야 할 작업
- Play 모드에서 확인할 내용
