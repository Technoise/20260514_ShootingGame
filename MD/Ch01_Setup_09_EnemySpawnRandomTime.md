# 요청

AGENTS.md 기준으로 작업해줘.

이번 단계에서는 적 생성 시간이 랜덤으로 바뀌도록 코드만 수정해줘.  
Unity Editor에서 필요한 작업은 내가 직접 할 거야.

## 작업 내용

1. 기존 `Assets/Scripts/EnemyManager.cs` 수정
2. 적 생성 최소 시간과 최대 시간 추가
3. 적이 생성될 시간을 랜덤으로 정하도록 수정

## 구현 기준

- 기존 EnemyManager의 적 생성 흐름은 유지해줘.
- 게임이 시작될 때 적 생성 시간을 랜덤으로 정해줘.
- 적이 한 번 생성된 뒤에는 다음 생성 시간도 다시 랜덤으로 정해줘.
- 최소 시간과 최대 시간은 Inspector에서 조절할 수 있게 해줘.
- 초보자가 이해하기 쉬운 단순한 코드로 작성해줘.

## 제한 사항

- 이번 단계에서는 적 생성 시간 랜덤화만 만들어줘.
- 다른 게임 기능은 아직 만들지 마.

## 완료 후 추가 보고 형식

- 수정한 스크립트 파일
- Inspector에서 조절할 수 있는 값
- Unity Editor에서 직접 해야 할 작업
- Play 모드에서 확인할 내용
