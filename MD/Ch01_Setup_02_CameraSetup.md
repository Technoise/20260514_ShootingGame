# 요청

AGENTS.md 기준으로 작업해줘.

이번 단계는 게임 기능을 만드는 단계가 아니라, 프로젝트 기본 설정을 확인하는 단계야.  
아래 내용만 확인하거나 필요한 경우 수정해줘.

## 작업 내용

1. 기본 씬의 `Main Camera` 설정 확인
   - Projection은 `Orthographic` 유지
   - 화면이 너무 좁지 않도록 Orthographic Size 조정

2. 입력 처리 설정 확인
   - 수업에서는 단순한 입력 방식을 사용할 예정
   - 필요한 경우 Unity 기본 Input과 Input System이 함께 동작하도록 설정

3. `.gitignore` 확인
   - 임시 파일이 Git에 들어가지 않도록 확인
   - 필요하면 아래 항목을 제외 처리
     - `patch.diff`
     - `.vsconfig`

## 제한 사항

- 이번 단계에서 요청한 내용만 확인해줘.
- 게임 기능은 아직 만들지 마.

## 완료 후 추가 보고 형식

- Main Camera에서 바뀐 값
- 입력 처리 설정에서 바뀐 값
