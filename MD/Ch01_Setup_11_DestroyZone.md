# 요청

AGENTS.md 기준으로 작업해줘.

이번 단계에서는 화면 밖으로 나간 오브젝트를 삭제하는 코드만 만들어줘.  
Unity Editor에서 필요한 작업은 내가 직접 할 거야.

## 작업 내용

1. `Assets/Scripts` 폴더가 없다면 생성
2. `Assets/Scripts/DestroyZone.cs` 생성
3. Trigger 영역에 들어온 오브젝트를 삭제하도록 구현

## 구현 기준

- 다른 오브젝트가 DestroyZone에 들어오면 삭제되게 해줘.
- Unity 3D Trigger 충돌을 기준으로 작성해줘.
- 초보자가 이해하기 쉬운 단순한 코드로 작성해줘.

## 제한 사항

- 이번 단계에서는 화면 밖 오브젝트 삭제 기능만 만들어줘.
- 다른 게임 기능은 아직 만들지 마.

## 완료 후 추가 보고 형식

- 새로 만든 스크립트 파일
- DestroyZone 오브젝트에 붙여야 할 스크립트 이름
- Unity Editor에서 직접 해야 할 작업
- Play 모드에서 확인할 내용
