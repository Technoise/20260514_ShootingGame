# 요청

AGENTS.md 기준으로 작업해줘.

이번 단계에서는 Enemy가 충돌할 때 폭발 이펙트가 나오도록 코드만 수정해줘.  
Unity Editor에서 필요한 작업은 내가 직접 할 거야.

## 작업 내용

1. 기존 `Assets/Scripts/Enemy.cs` 수정
2. Enemy가 사용할 폭발 이펙트를 Inspector에서 연결할 수 있게 하기
3. Enemy가 다른 오브젝트와 충돌하면 Enemy 위치에 폭발 이펙트 생성
4. 기존처럼 충돌한 상대 오브젝트와 Enemy 자신은 제거

## 구현 기준

- 폭발 이펙트 프리팹은 Inspector에서 연결할 수 있게 해줘.
- 충돌이 발생하면 Enemy가 있던 위치에 폭발 이펙트를 생성해줘.
- 기존 Enemy 충돌 제거 기능은 유지해줘.
- 초보자가 이해하기 쉬운 단순한 코드로 작성해줘.

## 제한 사항

- 이번 단계에서는 Enemy 충돌 시 폭발 이펙트 생성만 만들어줘.
- 다른 게임 기능은 아직 만들지 마.

## 완료 후 추가 보고 형식

- 수정한 스크립트 파일
- Inspector에서 연결해야 할 항목
- Unity Editor에서 직접 해야 할 작업
- Play 모드에서 확인할 내용
