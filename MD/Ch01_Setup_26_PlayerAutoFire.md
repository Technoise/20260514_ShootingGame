# 요청

AGENTS.md 기준으로 작업해줘.

이번 단계에서는 발사 버튼을 누르고 있으면 총알이 자동으로 계속 발사되도록 코드만 수정해줘.  
Unity Editor에서 필요한 작업은 내가 직접 할 거야.

## 작업 내용

1. 기존 `Assets/Scripts/PlayerFire.cs` 수정
2. 발사 버튼을 한 번 누르면 총알이 1발 발사되게 유지
3. 발사 버튼을 누르고 있으면 일정 시간마다 총알이 계속 발사되게 구현

## 구현 기준

- 발사 입력은 기존처럼 `Fire1`을 사용해줘.
- 버튼을 처음 누른 순간에는 바로 총알이 1발 나가게 해줘.
- 버튼을 계속 누르고 있으면 일정 시간마다 자동으로 총알이 나가게 해줘.
- 자동 발사 간격은 Inspector에서 조절할 수 있게 해줘.
- 기존 Bullet 프리팹과 발사 위치를 사용하는 구조는 유지해줘.
- 초보자가 이해하기 쉬운 단순한 코드로 작성해줘.

## 제한 사항

- 이번 단계에서는 플레이어 자동 발사 기능만 만들어줘.
- 다른 게임 기능은 아직 만들지 마.

## 완료 후 추가 보고 형식

- 수정한 스크립트 파일
- Inspector에서 조절할 수 있는 값
- Unity Editor에서 직접 해야 할 작업
- Play 모드에서 확인할 내용
