# 요청

AGENTS.md 기준으로 작업해줘.

이번 단계에서는 최고 점수가 저장되고 다시 불러와지도록 코드만 수정해줘.  
Unity Editor에서 필요한 작업은 내가 직접 할 거야.

## 작업 내용

1. 기존 `Assets/Scripts/ScoreManager.cs` 수정
2. 기존 `Assets/Scripts/Enemy.cs` 수정
3. 게임 시작 시 저장된 최고 점수 불러오기
4. 현재 점수가 최고 점수를 넘으면 최고 점수 저장하기

## 구현 기준

- 최고 점수 저장은 `PlayerPrefs`를 사용해줘.
- 게임 시작 시 저장된 최고 점수를 불러와 `bestScore`에 넣어줘.
- 불러온 최고 점수는 Text UI에 `최고 점수 : 점수` 형식으로 표시해줘.
- 예: `최고 점수 : 5`
- 현재 점수가 최고 점수보다 커지면 최고 점수를 갱신하고 저장해줘.
- 현재 점수 증가 방식은 기존 구조를 유지해줘.
- 초보자가 이해하기 쉬운 단순한 코드로 작성해줘.

## 제한 사항

- 이번 단계에서는 최고 점수 저장과 불러오기만 만들어줘.
- 다른 게임 기능은 아직 만들지 마.
