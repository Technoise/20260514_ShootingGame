# 요청

AGENTS.md 기준으로 작업해줘.

이번 단계에서는 현재 점수가 최고 점수를 넘으면 최고 점수도 화면에 표시되도록 코드만 수정해줘.  
Unity Editor에서 필요한 작업은 내가 직접 할 거야.

## 작업 내용

1. 기존 `Assets/Scripts/ScoreManager.cs` 수정
2. 기존 `Assets/Scripts/Enemy.cs` 수정
3. 최고 점수 Text UI를 Inspector에서 연결할 수 있게 하기
4. 현재 점수가 최고 점수보다 커지면 최고 점수를 갱신하기
5. 갱신된 최고 점수를 Text UI에 표시하기

## 구현 기준

- 최고 점수 Text UI는 Inspector에서 연결할 수 있게 해줘.
- 최고 점수는 0부터 시작하게 해줘.
- Enemy가 충돌로 제거될 때 현재 점수와 최고 점수를 비교해줘.
- 현재 점수가 최고 점수보다 크면 최고 점수도 같은 값으로 바꿔줘.
- 최고 점수는 Text UI에 `최고 점수 : 점수` 형식으로 표시해줘.
- 예: `최고 점수 : 5`
- 현재 점수 표시는 기존처럼 `현재 점수 : 점수` 형식을 유지해줘.
- PlayerPrefs 저장은 아직 사용하지 마.
- 초보자가 이해하기 쉬운 단순한 코드로 작성해줘.

## 제한 사항

- 이번 단계에서는 최고 점수 UI 갱신만 만들어줘.
- 다른 게임 기능은 아직 만들지 마.

## 완료 후 추가 보고 형식

- 수정한 스크립트 파일
- Inspector에서 연결해야 할 항목
- Unity Editor에서 직접 해야 할 작업
- Play 모드에서 확인할 내용
